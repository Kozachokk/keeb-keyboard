# keeb-keyboard
Custom keyboard for keeb hackclub

what you built, why, and what you learned

So I built a keyboard from scratch, including the pcb and the case themselves.
I started this project as sort of an introduction to electrical stuff and pcb designing.
During my journey, I learned a lot about pcb designing, wiring, placing vias, creating schematics. I also learned to do keyboard layout, how to use kicad and onshape, where I learned how to create keyboard cases
